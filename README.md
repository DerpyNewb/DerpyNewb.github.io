# Yohann Mar Gayao, projects

The source of https://derpynewb.github.io/: data, automation and QA tools, AI video ads, explainer videos cut by code, and a separate page of Total War: WARHAMMER III mods. The mods page says what's been checked for each mod and what hasn't, taken from each mod's own README.

`index.html` is the main page, `mods.html` the mods, and both share `style.css`. No build step and no JavaScript. The images in `img/` are screenshots from the projects' repos, a still from one of the ads and a frame of one explainer.
